# v2 shared text and plain digits

Roboto Mono Regular/Medium supply Latin/Cyrillic text. The small Roboto Regular/Medium subsets supply U+0030–0039 so zero has no dot or slash. Files were obtained from Google Fonts; glyphs were not edited. `RobotoMono-OFL.txt` and `Roboto-OFL.txt` contain the respective licenses. The interface hosts these assets locally for offline use. JetBrains Mono remains available for older cached surfaces.
